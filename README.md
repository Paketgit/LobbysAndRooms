## GameLobby Lite

Проект представляющий собой серверную часть веб-приложения для организации игровых лобби. 

Основной упор сделан на разработку бэкенда: архитектуру, маршрутизацию запросов, работу с базой данных и бизнес-логику. Клиентская часть (HTML/CSS) реализована в виде минимального html сайтика.

## Стек технологий
- **Backend:** PHP 8.3
- **Архитектура:** MVC
- **База данных:** MySQL 8.0
- **Инфраструктура:** Docker, Docker Compose
- **Frontend:** HTML5, CSS3

## Серверная логика
- **Аутентификация:** хеширование паролей (`password_hash`), сессии.
- **Лобби:** создание, чтение, проверка лимита игроков, роли (владелец/участник).
- **Связи:** таблица `members` для вступления и выхода.
- **Приглашения:** отправка, валидация, статусы (`pending`, `accepted`, `declined`).

## Запуск

Требования: Docker, Docker Compose.

1. Перейти в корневую папку проекта.
2. Выполнить: ```bash docker compose up --build```
